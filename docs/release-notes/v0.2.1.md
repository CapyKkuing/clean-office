편집 화면을 하나로 통일한 버전입니다. 이전 버전 위에 설치하면 업데이트됩니다(같은 서명).

## 바뀐 점
- **편집 화면 통일** — 워드·파워포인트·한글 모두 같은 도구모음(굵게·기울임·밑줄·글자색·정렬)을 씁니다. 새로 만들 때와 불러와서 편집할 때도 같은 화면입니다.
- **간단 편집 / 상세 편집** — 휴대폰은 간단 편집이 기본입니다. 위쪽 '상세 편집'을 누르면 모든 도구(슬라이드 추가·순서, 한글 표 편집 등)가 나오고, 고친 내용은 그대로 이어집니다. 고른 방식은 기억합니다.
- **새로 만들기** — 새 슬라이드, 새 한글 문서 추가
- **확대·축소** — −/＋ 버튼, 두 손가락 확대, Ctrl+휠 (PDF·워드·한글·파워포인트)
- **옛 DOC 열기 개선** — Word 97~2003, Word 6/95, RTF, HTML로 저장된 .doc 지원
- **앱 종료 확인** — 홈에서 뒤로 가기를 누르면 종료할지 묻습니다
- 안드로이드에서 깨지던 툴바 아이콘 수정, 홈 화면에 버전 표시

## 알아둘 점
- 한글 간단 편집은 글자와 기본 서식만 바꿉니다. 표·그림은 '상세 편집'에서 고치세요.
- PC↔폰 통신은 아직 암호화되지 않습니다. 집·사무실 와이파이에서만 쓰세요.
