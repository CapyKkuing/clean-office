파워포인트 상세 편집을 새로 만든 버전입니다. 이전 버전 위에 설치하면 업데이트됩니다(같은 서명).

## 새 기능 — 파워포인트 상세 편집
편집 화면 위쪽 **'상세 편집'**을 누르면 슬라이드를 그대로 보면서 고칠 수 있습니다.
- 도형·글상자·그림을 눌러 고르고, 끌어서 옮기고, 모서리로 크기 조절
- 글상자를 두 번 누르면 그 자리에서 글자 수정 (굵게·기울임·밑줄·색·크기·정렬)
- 글상자·도형(8종)·그림 넣기, 복제·삭제·앞뒤 순서·채우기 색, 되돌리기
- 슬라이드 목록: 새 슬라이드(레이아웃 선택)·복제·순서 바꾸기·삭제
- 공개 파일 표준(ECMA-376)만 보고 직접 만든 기능입니다. 저장한 파일은 파워포인트에서 그대로 열립니다.

## 고친 점
- 자동 생성 도구로 만든 PPT가 슬라이드로 안 보이고 글자만 나오던 문제
- 간단 편집에서 어두운 글자가 어두운 바탕에 묻혀 안 보이던 문제

## 알아둘 점
- 표·차트는 보기만 됩니다(내용 수정은 아직).
- 애니메이션·그림자 효과는 화면에 안 보이지만 파일에는 그대로 남습니다.
- PC↔폰 통신은 아직 암호화되지 않습니다. 집·사무실 와이파이에서만 쓰세요.
