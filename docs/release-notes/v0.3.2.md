삼성 인터넷 등에서 내려받은 문서를 바로 클린오피스로 열 수 있게 고친 버전입니다. 이전 버전 위에 설치하면 업데이트됩니다(같은 서명).

## 고친 점
- **'파일 열기' 목록에 클린오피스가 안 나오던 문제** — 정부·공공기관 사이트처럼 문서를 "일반 파일"(형식 표시 없음)로 내려보내면, 삼성 인터넷 다운로드 후 열기 목록에 클린오피스가 빠졌습니다. 이제 이런 파일도 받습니다.
- **이름으로 종류를 알 수 없는 파일도 열기** — `fileDown.do`처럼 확장자가 없거나 엉뚱한 이름이어도 파일 내용을 보고 한글(HWP·HWPX)·워드(DOC·DOCX)·엑셀(XLS·XLSX)·파워포인트(PPT·PPTX)·PDF·그림을 알아내 엽니다.
- 한글·엑셀 문서의 다른 형식 표시(`application/hwp`, 매크로 엑셀, ODS 등)도 추가로 받습니다.

## 설치
아래 **CleanOffice-0.3.2.apk**(또는 CleanOffice.apk — 같은 파일)를 내려받아 설치합니다.
