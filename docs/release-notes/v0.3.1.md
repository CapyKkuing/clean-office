파워포인트 보기 화면을 다듬은 버전입니다. 이전 버전 위에 설치하면 업데이트됩니다(같은 서명).

## 고친 점
- **모든 슬라이드를 아래로 이어서 보기** — 휴대폰에서 첫 슬라이드만 보이고 나머지는 작은 칸 안에서 따로 넘겨야 했던 문제
- **보기 화면도 편집기와 같은 방식으로 그림** — 본문 글자가 너무 작게 나오거나 글머리 기호가 빠지던 문제. 보는 화면과 고치는 화면이 똑같이 보입니다.
- '새 슬라이드' 메뉴가 화면 왼쪽 밖으로 잘리던 문제

## 보안 점검 반영 (코드 검토 + 공격 시나리오 테스트)
- **[높음] 조작된 PPT 파일로 앱 안에서 코드 실행** — 글꼴 이름·색 값이 화면 코드에 그대로 들어가던 문제. 값을 검증하고, 만든 화면 내용을 한 번 더 걸러서(DOMPurify) 넣습니다. 한글 간단 편집도 같은 방식으로 보강.
- **[중간] 조작된 .doc 파일로 앱이 멈춤** — 길이 값을 잘못 읽어 무한 반복되던 문제 수정. 조작된 .ppt 로 메모리를 채우는 경우도 제한.
- **[중간] PC 연결** — 집·사무실 네트워크 주소(사설 IP)만 받고, QR을 찍으면 어느 PC인지 확인 창을 띄웁니다. 연결 코드를 보내기 전에 그 주소의 서버가 같은 코드를 아는지 서명으로 확인하므로, 남의 기기에 코드가 새지 않습니다.
- **[중간] PC 공유 폴더** — 문서·그림 형식만 올릴 수 있고(바로가기·실행 파일 차단), 같은 네트워크에서 온 요청만 받습니다. 동시 업로드 수 제한, 실패한 임시 파일 정리.
- **[중간] 안드로이드** — 앱이 열 수 있는 파일을 "사용자가 직접 고른 파일"로 제한, 다른 앱이 넘긴 주소는 content:// 만 받음, 최근 목록에서 뺀 파일의 접근 권한 반납, 불필요한 저장소 권한 제거.
- 비밀값·개인정보 검사: 저장소·빌드 결과물·커밋 기록 모두 이상 없음.

> **PC 서버 사용자**: 폰이 연결 전에 PC를 확인하는 절차가 추가되어, PC 쪽 클린오피스도 0.3.1로 업데이트해야 연결됩니다.
