한글 편집과 파워포인트 편집이 들어간 버전입니다. 이전 버전 위에 설치하면 업데이트됩니다(같은 서명).

## 새 기능
- **한글(HWP·HWPX) 편집** — 한글처럼 메뉴·툴바·표 편집. 인터넷 연결 없이 동작합니다. (rhwp-studio 내장)
- **파워포인트(PPTX) 글자 편집** — 디자인은 그대로 두고 글자 수정, 슬라이드 순서 바꾸기·삭제
- **옛 DOC·PPT 열기** — 글자를 꺼내 보여 주고 DOCX·PPTX로 바꿔 편집
- **새 디자인** — 둥근 모서리, 부드러운 그림자, 정돈된 간격
- **QR로 바로 받기** — README의 QR을 찍으면 최신 APK가 바로 내려받아집니다

## 알아둘 점
- 한글 편집 엔진이 들어가 APK가 약 39MB로 커졌습니다.
- 휴대폰에서 한글 편집기는 PC용 화면이라 메뉴가 작게 보입니다. 보기는 기존처럼 크게 나옵니다.
- 옛 DOC·PPT는 글자만 가져옵니다(서식·그림 제외).
- PC↔폰 통신은 아직 암호화되지 않습니다. 집·사무실 와이파이에서만 쓰세요.
